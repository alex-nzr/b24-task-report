# Bitrix24 UI Kit implementation plan

> Execute inline with executing-plans and TDD; preserve the user's index and master workspace.

**Goal:** Replace the report interface with the official Bitrix24 UI Kit, as approved in chat.
**Architecture:** Vue mounts one page inside B24App. Symfony still renders a safe initial HTML fallback and whitelisted page data; forms submit to existing Symfony routes with the same CSRF tokens. No SPA router, API rewrite or client-side webhook.
**Tech stack:** PHP 8.3, PostgreSQL 15, Symfony 7.4, Vue 3.5+, Vite, Tailwind 4, @bitrix24/b24ui-nuxt.
**Spec:** The approved chat design: official components/tokens, existing backend retained; UI choice recorded in AGENTS.md and STYLE.md.

## Constraints

- No direct reading or printing of .env credentials. Vite must not load backend dotenv files.
- No deployment, commit, worktree, change of agent model or unrelated backend changes.
- Maintain login, validation, saved results, progress, totals, role, CSV, detail records, task links and visibility notices.
- Use official MCP documentation and installed package contracts, not a CSS imitation.
- Mobile widths and keyboard access must remain usable; colors are not the only indication of status.

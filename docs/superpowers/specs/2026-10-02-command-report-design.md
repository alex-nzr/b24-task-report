# Сбор отчёта Command: утверждённая схема

Пользователь подтвердил схему в чате, затем уточнил: OpenServer не настраивать,
команду запускать вручную; на production запускать cron. По умолчанию 45 секунд.

## Запуск

`app:reports:collect --time-limit=45` выбирает готовые к обработке report_runs
из PostgreSQL, без Messenger и постоянного worker. Один глобальный advisory lock
защищает REST-лимит. Команда выходит сразу при пустом списке; время — мягкий
бюджет между шагами, выполняющийся REST-запрос/задача заканчивается перед выходом.
Прогресс существующих отчётов сохраняется; pending_tasks/cursor_id продолжаются.
Новые задания — одна запись report_runs, не сообщения очереди.

## Ошибки и достоверность

Сохранять этап, ID/название задачи (если известны), безопасный код, попытки,
состояние и время следующего повтора в report_errors. Не хранить URL вебхука,
текст исключений/ответов, токены. Глобальные ошибки списка имеют task_id NULL.
Временные ошибки: максимум пять неуспешных попыток на шаг, кроме лимита времени
метода OPERATION_TIME_LIMIT, который ждёт сброса лимита без исчерпания бюджета.
Неповторяемая ошибка задачи либо исчерпание повторов: сохранить ошибку и продолжить
следующую задачу. Ошибка списка: после исчерпания повторов failed, список неполон.
Если время известно, а роль нет: сохранить время, роль «Не удалось определить».
Если время неизвестно: не записывать фиктивный ноль. После обхода complete либо
complete_with_errors по наличию нерешённых ошибок; итог в последнем случае неполный.
История resolved сохраняется для диагностики, но не делает итог ошибочным.

## Представление

Показывать сохранённые строки и промежуточную сумму при любом статусе.
Убрать meta refresh. Авторизованный GET progress возвращает whitelisted JSON
из БД без REST-вызовов; Vue обновляет данные раз в пять секунд без навигации,
останавливается при терминальном статусе/уничтожении компонента. Ошибки чтения
прогресса отображаются, форма и уже известные данные не теряются.
CSV доступен для текущего снимка, включает статус полноты и ошибки. Это ответ
HTTP, не постоянный файл; хранение результата — report_runs/report_tasks/errors.
Purge удаляет terminal отчёты старше семи дней по created_at, каскадно строки
и ошибки; queued/running/waiting не удаляет. UI остаётся официальным B24 UI Kit.
